## Featured Projects

### FEVER Evidence Search
Neural information retrieval system for evidence retrieval on the FEVER dataset.

- Built an embedding and indexing pipeline with Sentence Transformers and FAISS
- Compared Flat, PQ, IVF, HNSW and OPQ indexes
- Achieved **nDCG@10 = 0.9154**
- Reduced index size from **1.4 GB to 95 MB**
- Fine-tuned embeddings using hard negative mining

`Python` `PyTorch` `Sentence Transformers` `FAISS` `NLP`
